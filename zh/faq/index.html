关于我们的在线 HTML 编译器的常见问题。

了解使用 LadeCompile 所需的一切 — 免费、免登录的 HTML、CSS 与 JavaScript 编译器，在浏览器中即时运行。

什么是 HTML 编译器？

HTML 编译器（更准确地说是 HTML 在线编辑器 / HTML在线编译器）是一款让你在浏览器中直接编写 HTML、CSS 与 JavaScript 并即时查看渲染效果的工具 — 无需本地环境，无需下载。LadeCompile 是一款 免费在线 HTML 编译器，在沙盒预览中实时运行你的代码。

HTML 是用来做什么的？

HTML（超文本标记语言）是构建网页内容的标准标记语言 — 标题、段落、链接、图片、表单与布局。你访问的每个网页都以 HTML 为基础，配合 CSS 负责样式、JavaScript 负责交互。

什么是在线编译器？

在线编译器是一款无需在本地安装任何软件、直接在浏览器中编译或运行代码的网页工具。对于 HTML/CSS/JS 来说，“编译”实际上就是渲染 — 工具解析你的代码并即时显示实时预览。

什么是编译器？

编译器将源代码转换为机器或浏览器可执行的形式。对于 HTML、CSS 与 JavaScript，并没有传统的编译步骤 — 浏览器直接解释执行 — 但像 LadeCompile 这样的工具仍被称为“HTML 编译器”，因为它们提供了即写即预览的体验。

写 HTML 要用什么工具？

你可以在任意文本编辑器（VS Code、Sublime、记事本）中编写 HTML 并在浏览器中打开，也可以使用像 LadeCompile 这样的 在线 HTML 编译器，它将代码编辑器与实时预览合二为一 — 无需配置。

HTML 需要编译器吗？

不需要。HTML 不需要编译 — 浏览器直接渲染。所谓“在线 HTML 编译器”其实是代码编辑器 + 实时预览的组合，适合快速测试、学习与分享代码片段，无需搭建本地开发环境。

如何在在线编译器中运行 HTML 代码？

在编辑器的 HTML 标签页中粘贴或输入你的 HTML，如需 CSS 与 JS 也可在对应标签页中添加，实时预览会自动更新（或点击运行）。无需登录，无需下载 — 在浏览器中即时运行。打开 LadeCompile 编辑器试试。

如何在 HTML 在线编译器中添加图片？

使用 <img> 标签并填入在线图片地址：<img src="https://example.com/image.jpg" alt="描述">。由于大多数在线 HTML 编译器（包括 LadeCompile）不支持将本地文件上传到沙盒，请使用在线托管的图片（如 Imgur、Cloudinary 或你自己的 CDN）作为 src。

有，LadeCompile 支持全屏编辑器视图，让你可以专注于代码与预览，不受浏览器外壳或侧边栏干扰 — 适合演示、教学或深度专注的编码场景。
